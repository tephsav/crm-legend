Раньше менеджеры вели заявки в Excel и почте, из-за чего часть заявок терялась и возникали дубли. Это приводило к потере потенциальных клиентов и дохода банка. Для решения проблемы была разработана CRM для управления лидами и сделками. CRM автоматизировала обработку лидов, сопровождение их по этапам квалификации и подготовку к сделкам по банковским продуктам для бизнеса. Я принимал участие в разработке и доработке backend-части приложения: реализовывал CRUD-функциональность, REST API, бизнес-логику, взаимодействие с базой данных и покрывал код тестами. Проект строился на Java и Spring Boot с использованием PostgreSQL, Liquibase, JTE, Gradle, Docker, JUnit и Mockito. Разработка велась по спринтам, изменения проходили код-ревью, для контроля версий использовали Git.

Приложение подключается к PostgreSQL напрямую через JDBC, используя секреты из Vault. Разработчики работают с базой только через pgAdmin, который используется для просмотра данных и диагностики. Доступы к pgAdmin и PostgreSQL хранятся в Vault и не размещаются в репозитории или конфигурационных файлах проекта.
