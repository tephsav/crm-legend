## ONB-2: Vault — твой главный ключ
**Ошибка `permission denied`**.  
Причина: токен валиден, но этот путь не твой.  
Действие: вернуться на свой путь `secret/<slug>/dev/`; чужие пути и не должны открываться.

**Ошибка `invalid token`**.  
Причина: токен неверный, истёк или не вставлен.  
Действие: взять токен из письма точно, без лишних пробелов; не подходит — ментору на перевыпуск

## ONB-3: Корпоративный Git (Gitea)
**Настройка доступа к Gitea через SSH.**  
Проверка: `ssh -T git@gitea.mentee-power.ru`  

**Получено сообщение:**  
`Hi there, <username>! You've successfully authenticated with the key named SSH-key, but Gitea does not provide shell access.
If this is unexpected, please log in with password and setup Gitea under another user.`

**Типичная ошибка**:  
`Permission denied (publickey) либо Authentication failed`

**Причина**:  
Сервер не знает мой публичный ключ.

**Исправление**:  
добавить `id_ed25519.pub` в `Settings → SSH Keys`.

**Почему публичный ключ можно хранить на сервере**:  
сервер использует его только для проверки подписи.

**Почему приватный ключ нельзя**:  
он позволяет выдавать себя за владельца аккаунта.
